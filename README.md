# The Internet in One Word

Entered in [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) on make.fun.

## The word

> unhinged

8 characters — a single word, inside the 30-character limit.

## What this entry does

`main.ts` (Node 22+) writes exactly one word describing the whole internet
to `/output/entry.txt`. The program is deterministic, uses no network, and
has no dependencies — it only creates `/output` if missing and writes the
word as UTF-8 text.

## How to run

```sh
node main.ts
cat /output/entry.txt
```
